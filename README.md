
# CodeAlpha EDA Task 2

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a books dataset collected through web scraping.

## Objectives
- Understand the structure of the dataset
- Identify patterns and trends
- Analyze book ratings and prices
- Generate meaningful insights from the data

## Dataset Information
The dataset contains:
- Book Title
- Price
- Rating

Total Records: 1000

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Dataset inspection using df.info()
- Missing value analysis
- Rating distribution analysis
- Price statistics analysis
- Identification of highest and lowest priced books
- Top 10 expensive books analysis

## Key Findings
- Total books analyzed: 1000
- Ratings range from One to Five stars
- Price distribution was analyzed using descriptive statistics
- Most common ratings were identified
